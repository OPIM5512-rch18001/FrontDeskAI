# Drop-in photos

The site ships with generated artwork so it looks finished without any photos.
To use a real photo, save it in this folder with one of the names below
(`.jpg`, `.jpeg`, `.png`, `.webp` or `.avif`). It replaces the matching artwork
automatically. No code changes, just refresh.

| File name        | Where it appears                          | Suggested shape        |
|------------------|-------------------------------------------|------------------------|
| `hero`           | Home page, big card beside the headline   | portrait (4:5), 1600px tall |
| `reform`         | Home page, Reform studio tile             | landscape, 1400px wide |
| `cs4`            | Home page, CS4 studio tile                | landscape, 1400px wide |
| `ride`           | Home page, Ride studio tile               | landscape, 1000px wide |
| `box`            | Home page, Box studio tile                | landscape, 1000px wide |
| `sweat`          | Home page, Sweat+ studio tile             | landscape, 1000px wide |
| `cta`            | Home page, dark "Skip the line" banner    | wide, 2000px           |
| `membership`     | Membership page, dark banner              | wide, 2000px           |

Tips
- Use photos you own or that come with a license that allows this use
  (Unsplash and Pexels are common sources; check each photo's license).
- Do **not** use photos from the real Club Studio website.
- White text sits on top of the studio tiles, so darker or moodier photos read best.
- Keep files under about 500 KB each for fast loading.
